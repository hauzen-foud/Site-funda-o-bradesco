FUNDAMENTOS

As tecnologias da Web

HTML, CSS e JavaScript possuem funções diferentes, mas trabalham juntos para criar páginas completas, bonitas e interativas.
HTML

HTML

Estrutura

O HTML organiza o conteúdo de uma página. Ele permite criar títulos, textos, imagens, links, formulários, botões e outras estruturas.

HTML significa HyperText Markup Language e é usado para criar a estrutura das páginas da web. Com ele, podemos organizar textos, imagens, links, formulários, botões e outros elementos que fazem parte de um site.

CSS

CSS

Aparência

O CSS controla a aparência do site. Com ele podemos definir cores, tamanhos, espaçamentos, layouts, animações e muito mais.

CSS significa Cascading Style Sheets e é usado para personalizar a aparência das páginas. Ele permite modificar cores, fontes, tamanhos, espaçamentos, layouts, animações e diversos outros elementos visuais do site.

JS

JavaScript

Interação

JavaScript permite criar interações. Botões, menus, animações, formulários e diversos recursos podem ser controlados através dele.

JavaScript é uma linguagem de programação usada para adicionar interatividade às páginas. Com ele, é possível criar menus, animações, validações de formulários, botões interativos e muitos outros recursos.
